# &lt;mark&gt;

가사를 따라가며 듣는 웹 음악 플레이어. 휴대폰에 있는 음악 파일과 LRC·SRT 가사를 불러와, 지금 부르는 줄을 네모 상자가 따라갑니다.

**바로 쓰기:** https://ys222k2-blip.github.io/markplayer/

설치도 서버도 필요 없는 HTML 파일 하나(`index.html`)입니다. 고른 파일은 기기 밖으로 나가지 않고 브라우저 안에서만 재생됩니다. (앨범 탭의 표지는 RJ 번호로 DLsite 이미지 서버에서 받아 옵니다.)

## 기능

- 폴더 추가하기(iOS 18.4 이상) 또는 파일 여러 개 고르기. 폴더는 기본으로 그 안에 바로 든 파일만 넣음(설정 › 일반 › 하위 폴더도 추가를 켜면 하위 폴더의 곡도 넣음)
- PC에서는 파일이나 폴더를 화면에 끌어다 놓아도 추가됨
- 곡과 이름이 같은 `.lrc` · `.srt` · `.vtt` 가사를 자동으로 연결 (`곡.ko.srt`처럼 뒤에 붙은 이름도 찾음)
- 비공개 GitHub 자막 저장소 연결: 폴더 이름의 RJ 번호(없으면 성우 이름)로 자막을 찾아, 곡을 추가할 때 받아 둠
- 일본어 자막(`곡.ja.srt`)을 한국어 아래에 함께 보기 (설정 › 가사, 기본은 한국어만)
- 곡·작품 이름을 기본(파일·폴더 이름 그대로) · 한국어 · 일본어 · 한/일 · 일/한으로 보기(설정 › 일반). 재생목록·재생 칸·앨범 탭·잠금 화면에 함께 적용
  - 한/일은 한국어를 크게, 일본어를 그 아래 작고 흐리게 보여줌(일/한은 반대). 재생목록의 작품 이름 줄과 재생 칸에는 큰 쪽만 보임
  - 한국어·일본어 이름은 자막 저장소에서 가져옴: 작품 폴더의 `트랙명.md`(작품의 한국어 이름과 트랙 파일명의 일본어 ↔ 한국어 표), 없으면 목록 README. 일본어 작품 이름은 저장소 자막 폴더 이름. 저장소에 없는 곡은 기본 이름을 씀
- 앨범 탭: 지금 곡의 작품명을 크게(줄바꿈해서 끝까지), 곡 이름은 작게 보여줌
  - RJ 번호가 있으면 DLsite 표지를 받아 보여주고 **DLsite에서 보기** 버튼을 띄움. 표지는 한 번 받으면 이 기기에 저장되어 인터넷 없이도 보임
  - 저장소 자막을 쓰는 곡이면(RJ 번호가 없는 곡도) **자막 폴더 열기** 버튼으로 GitHub의 그 폴더를 엶
  - 작품명 앞에는 RJ 번호를 붙임(길게 누르면 번호만 한 번에 선택돼 복사하기 쉬움)
  - 기본 작품명은 곡이 들어 있는 폴더 이름에서 RJ 번호를 뺀 것(`mp3`, `WAV版` 같은 폴더는 건너뜀), 그것이 없으면 저장소 자막 폴더 이름(`RJ번호_작품명`)에서 가져옴
  - 한국어 이름은 작품 폴더의 `트랙명.md`(`- 한국어:` 줄과 표), 없으면 `subtitles/README.md`(작품마다 `<!-- 폴더 이름 -->` 다음 줄의 `**한글 제목**`)와 폴더 안 `README.md`(`1. 한글 제목 <!-- 원래 트랙 이름 -->`)에서 읽음
- 가사 줄을 누르면 그 위치로 이동, 손으로 넘겨 보다가 놓으면 현재 줄로 복귀
- 곡마다 가사 싱크 조절, 글자 크기·정렬·글꼴 설정
- 가변 비트레이트(VBR) MP3 경고: 재생목록에 `VBR` 표시. 가사가 있는 곡은 처음 재생할 때 알려 주고, 가사 탭의 **VBR 주의**를 누르면 다시 보여 줌
  - VBR MP3는 건너뛰거나 이어 들을 때 브라우저가 위치와 시각을 어림해서 가사가 몇 초씩 밀릴 수 있음. 처음부터 들으면 맞고, 고정 비트레이트(CBR)로 다시 인코딩하면 어디서든 맞음
- 전체재생 · 전체반복 · 셔플 · 한곡반복 · 한곡재생, 재생 속도, 수면 타이머, 뒤로·앞으로 건너뛰기(5·10·15·30초, 기본 10초)
- 잠금 화면 조작, 드래그로 순서 바꾸기, 지난번 목록과 위치 이어 듣기
- 한 손으로 쓰도록 모든 버튼을 화면 아래에: 맨 아래 로고와 탭(재생목록·앨범·가사), 그 위 재생 칸, 콘텐츠 바로 아래 탭별 버튼
- 화면을 손가락으로 좌우로 밀어 탭 넘기기. 탭은 돌아가며 이어져서 가사에서 왼쪽으로 밀면 재생목록, 재생목록에서 오른쪽으로 밀면 가사(터치만. PC에서는 숫자 키 1·2·3으로 탭 고르기)
- 로고를 누르면 설정: 창 아래의 탭으로 **일반**과 **가사**를 오감. 가사 탭에서 열면 가사 설정부터 보임
  - 일반: 화면 테마(시스템 · 밝게 · 어둡게), 곡·작품 이름(기본 · 한국어 · 일본어 · 한/일 · 일/한), 하위 폴더도 추가(기본 끔), 건너뛰기 간격, 새로 고침과 지금 쓰는 판
  - 가사: 싱크, 글자 크기 · 정렬 · 글꼴, 자막 언어, 스크롤 후 자동 복귀, 화면 켜두기, 자막 저장소

## 자막 저장소 연결

비공개 GitHub 저장소의 `<RJ번호_작품명>/<트랙명>.lrc · .ko.srt · .ja.srt` 자막을 불러옵니다. 설정은 **로고 › 설정 › 가사 › 자막 저장소**에 있습니다.

1. GitHub › Settings › Developer settings › **Fine-grained tokens** › Generate new token
   - Repository access: **Only select repositories** → 자막 저장소 하나만
   - Permissions: **Contents: Read-only** (Metadata 읽기는 자동으로 붙음)
2. 자막 저장소 화면에 저장소 이름(`owner/repo`)과 토큰을 넣고 **연결**을 누릅니다. 저장소 이름은 페이지에 들어 있지 않고 이 기기에만 저장됩니다.

- 파일 목록은 한 번 받아 두고, 곡을 추가할 때 저장소가 바뀌었는지만 확인합니다(10분에 한 번). 바뀌었을 때만 목록을 다시 받습니다. 곡·작품 이름에 쓸 작품 폴더의 `트랙명.md`와 README.md도 이때 함께 받아 둡니다(바뀐 파일만 새로 받음).
- 맞는 곡의 자막은 곡을 추가할 때 바로 받아 두어, 인터넷이 없어도 보입니다.
- 찾는 순서
  1. 파일 이름이나 폴더 이름에 RJ 번호가 있으면 그 번호로 시작하는 폴더에서 같은 이름의 트랙을 찾습니다. 파일 이름을 한국어로 바꾼 곡(저장소의 파일명 한-일 전환 bat)은 `트랙명.md` 표로 일본어 이름을 찾아 맞춥니다. 이름이 다르면(예: `01.mp3`) 트랙 번호가 하나만 맞을 때 그 트랙을 씁니다.
  2. RJ 번호가 없으면 성우 이름 폴더(예: `성우이름 한글이름`)에서 같은 이름의 트랙을 찾고, 없으면 저장소 전체에서 이름이 같은 트랙을 찾습니다.
  3. 같은 번호의 폴더가 여러 개면(`…_2`) 곡이 더 많이 맞는 폴더를 고르고, 자막 저장소 화면에서 바꿀 수 있습니다.
- 곡 옆에 가사 파일이 있어도 저장소 자막을 먼저 씁니다. 저장소 자막 쓰기를 끄면 곡 옆의 파일만 씁니다.
- 저장소 이름과 토큰은 이 기기 브라우저(localStorage)에만 저장됩니다. `ys222k2-blip.github.io` 아래의 다른 Pages 사이트와 저장 공간을 함께 쓰므로, 토큰 권한은 자막 저장소 읽기로만 좁혀 두세요. **연결 끊기**는 토큰과 받아 둔 자막을 지웁니다.

## 아이폰에서 앱처럼 쓰기

Safari로 위 주소를 열고 공유 버튼 → **홈 화면에 추가**를 누르면 전체 화면 앱처럼 열립니다.

홈 화면 앱에는 새로 고침 버튼이 없어서, 새 판으로 바꾸려면 **로고 › 설정 › 일반**의 **새로 고침**을 누릅니다. 새로 고치면 재생목록이 비니, 같은 폴더를 다시 추가하면 순서와 듣던 위치를 이어서 불러옵니다.

화면 시안과 예전 배치로 돌아가는 방법은 [design/](design/README.md)에 있습니다.

## GitHub Pages로 배포하기

이 저장소는 빌드 과정이 없어 `index.html`을 그대로 서비스합니다.

1. 저장소의 **Settings → Pages**로 이동
2. **Build and deployment → Source**를 `Deploy from a branch`로 선택
3. **Branch**에서 `index.html`이 있는 브랜치와 `/ (root)`를 고르고 **Save**
4. 1~2분 뒤 `https://ys222k2-blip.github.io/markplayer/`에서 열림

`.nojekyll` 파일은 GitHub Pages가 Jekyll 변환 없이 파일을 그대로 올리게 합니다.
